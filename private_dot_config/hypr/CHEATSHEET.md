# Hyprland 快捷键速查(主键 = ALT)

## 🪟 窗口操作
| 按键 | 功能 |
|---|---|
| `ALT + Shift + P` | 关闭窗口 |
| `ALT + Shift + Space` | 浮动 ⇄ 平铺 |
| `ALT + F` | 全屏 |
| `ALT + Y` | 钉住(所有工作区可见) |
| `ALT + P` | 伪平铺 |
| `ALT + Tab` | 组内下一个窗口 |
| `ALT + 左键拖动` | 移动窗口 |
| `ALT + 右键拖动` | 调整窗口大小 |

## 📐 调整大小
| 按键 | 功能 |
|---|---|
| `ALT + R` | 进入调整大小模式(方向/hjkl 连发,`Esc` 退出) |
| `Ctrl + Shift + 方向/hjkl` | 直接调整大小 |

## 🖥️ 工作区
| 按键 | 功能 |
|---|---|
| `ALT + 1~0` | 切到工作区 1~10 |
| `ALT + L` / `ALT + H` | 下一个 / 上一个工作区 |
| `ALT + .` / `ALT + ,` | 下一个 / 上一个(存在的)工作区 |
| `ALT + /` | 回到刚才的工作区 |
| `ALT + 滚轮` | 滚动切换工作区 |
| `ALT + Q` | QQ 工作区(并启动 QQ) |
| `ALT + T` | TG 工作区(并启动 Telegram) |
| `ALT + M` / `N` / `O` | Music / Note / OB(Obsidian) 工作区 |
| `ALT + O` | 顺带开关 waybar |

## 📦 Scratchpad(临时抽屉)
| 按键 | 功能 |
|---|---|
| `ALT + -` | 把当前窗口扔进 scratchpad |
| `ALT + =` | 显示 / 隐藏 scratchpad |

## 🚀 启动应用
| 按键 | 功能 |
|---|---|
| `Super`(单独按) | 应用启动器 hyprlauncher |
| `ALT + Super_L` | 电源菜单 wlogout |
| `ALT + Return` | 终端 kitty |
| `ALT + Shift + Return` | 浮动终端 |
| `ALT + B` | Chrome |
| `ALT + Shift + O` | Obsidian |
| `ALT + Shift + N` | 浮动终端里打开 nvim 笔记 |
| `ALT + Shift + M` | musicfox(重启 mpd) |
| `ALT + Z` | Zotero |
| `ALT + S` | rofi 网页搜索 |

## 🌐 窗口间移动(你记得的那几个)
| 按键 | 功能 |
|---|---|
| `ALT + 方向键` | 移动焦点 |
| `ALT + Shift + 方向键` | 移动窗口位置 |
| `ALT + Ctrl + 1~0` | 窗口移到工作区 1~10 |
| `ALT + Ctrl + ←/→` | 窗口移到上/下一个工作区 |
| `ALT + Shift + 1~0` | 窗口移到工作区(不跟随跳转) |

## 📸 截图 / 翻译 / 剪贴板
| 按键 | 功能 |
|---|---|
| `ALT + [` | 截图保存到 ~/图片 |
| `ALT + ]` | 截图并发送到 swappy 编辑 |
| `ALT + X` | pot:截图 OCR 识别 |
| `ALT + C` | pot:截图翻译 |
| `ALT + A` | pot:划词翻译 |
| `ALT + V` | 剪贴板历史选择 |

## 🔊 功能键
| 按键 | 功能 |
|---|---|
| `音量+` / `音量-` / `静音` | 音量(wpctl) |
| `麦克风静音` | 麦克风开关 |
| `亮度+` / `亮度-` | 屏幕亮度(brightnessctl) |
| `播放/上一首/下一首` | mpd(mpc) |

## 🧹 间隙
| 按键 | 功能 |
|---|---|
| `ALT + G` | 间隙清零(无缝模式) |
| `ALT + Shift + G` | 恢复默认间隙(5/3) |

## ⚠️ 危险区
| 按键 | 功能 |
|---|---|
| `ALT + Shift + Q` | **退出 Hyprland** |

## 🆕 2026 新增
| 按键 | 功能 |
|---|---|
| `ALT + I` | 通知中心面板(swaync,含历史/勿扰) |
| `ALT + Shift + R` | 屏幕录制开关(wf-recorder → ~/视频/) |
| `音量键` / `亮度键` | 屏幕弹出 OSD 指示条(swayosd) |
| `ALT + ~` | 全局工作区概览(hyprexpo 插件) |
| `ALT + Ctrl + L` | 切换 scrolling 布局试玩 |
| `ALT + F10` | 护眼模式开关(hyprsunset 4500K) |
